# 미션 - 개발자 비상근무

## 기능 구현 목록
1. 비상 근무를 배정할 월과 시작 요일 입력
  - 예외 사항
    - 형식이 올바르지 않은 경우
      - 잘못된 형식입니다.
    - 월이 1~12가 아닌 경우
      - 잘못된 월입니다.
    - 요일이 월~일이 아닌 경우
      - 잘못된 요일입니다.
2. 평일 및 휴일 비상 근무 순번대로 사원 닉네임 입력
  - 예외 사항
    - 형식이 올바르지 않은 경우
      - 잘못된 형식입니다.
    - 이름이 중복인 경우
      - 이름이 중복입니다.
    - 이름이 0자 또는 5자 초과인 경우
      - 이름은 1자 이상 5자 이하로 입력해야 합니다.
    - 인원이 5명 미만이거나 35명 초과인 경우
      - 인원은 5명 이상 35명 이하로 입력해야 합니다.
    - (휴일) 평일 비상 근무자 목록과 일치하지 않는 경우
      - 평일 비상 근무자 목록과 다릅니다.
3. 비상 근무자 배정
  1. 날짜를 순회하면서 각 날짜에 맞는 비상 근무자를 배정한다.
    - 평일인 경우
      - 평일 근무자 목록 중 다음 차례 근무자를 배정한다.
        - 만약 이전 날짜의 근무자와 동일하다면 그 다음 차례 근무자를 배정한다.
    - 휴일인 경우
      - 휴일 근무자 목록 중 다음 차례 근무자를 배정한다.
        - 만약 이전 날짜의 근무자와 동일하다면 그 다음 차례 근무자를 배정한다.
