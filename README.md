# 미션 - 개발자 비상근무

## 기능 구현 목록

1. 비상 근무 배정 월, 시작 요일 입력 및 검증
    - 예외 사항
        1. 공백이면 예외 발생
        2. 형식에 맞지 않은 입력이면 예외 발생
        3. 첫번째 요소가 숫자가 아니면 예외 발생
        4. 첫번째 요소가 1~12가 아니면 예외 발생
        5. 두번째 요소가 요일(월~일)이 아니면 예외 발생
2. 입력받은 월의 정보 생성
    1. 월 정보 할당
    2. 날짜 정보 할당
    3. 요일 정보 할당
    4. 평일인데 휴일인지 유무 할당
    5. 근무자 변수 생성(아직 미할당)
3. 평일 비상 근무 사원 입력 및 검증
    - 예외 사항
        1. 공백이면 예외 발생
        2. 형식에 맞지 않은 입력이면 예외 발생
        3. 근무자 이름이 1~5자가 아니면 예외 발생
        4. 근무자 인원이 5~35명이 아니면 예외 발생
        5. 중복이 있으면 예외 발생
4. 평일 근무자 순번 목록 할당
5. 주말 비상 근무 사원 입력 및 검증
    - 예외 사항
        1. 공백이면 예외 발생
        2. 형식에 맞지 않은 입력이면 예외 발생
        3. 근무자 이름이 1~5자가 아니면 예외 발생
        4. 근무자 인원이 5~35명이 아니면 예외 발생
        5. 중복이 있으면 예외 발생
        6. 평일 비상 근무 사원 목록과 일치하지 않으면 예외 발생
6. 주말 근무자 순번 목록 할당
7. 날짜 차례대로 근무자 배정
    - 같은 근무자가 2일 연속 근무하지 않도록 구현
8. 결과 출력
    - 날짜 순서대로 “월, 일, 요일, (평일인데 휴일인 경우), 근무자 이름”을 출력한다.
